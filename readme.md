# AI Ticket Intelligence System

## Overview

AI-powered support ticket analysis platform that extracts:

- Summary
- Priority
- Category
- Platform
- Investigation Steps

## Features

- Ticket Summarization
- Priority Classification
- Category Detection
- Platform Identification
- AI Investigation Guidance

## Tech Stack

- Python
- Streamlit
- Gemini API
- JSON
- OOP

## Architecture

User
 ↓
Streamlit
 ↓
Ticket Processor
 ↓
Gemini API
 ↓
Structured JSON
 ↓
Storage
